# How to Make a God

A 3D presentation on Paul Atreides in the Dune films, for INSEAD Power and Politics.

Live deck: https://refraindre10-creator.github.io/how-to-make-a-god/

Open it in Chrome. → advances, P opens the presenter view with notes and timer, H lists every key, and M turns the background music on or off. The music starts with the first click or key press. The clip links on the five-sources slide play inside the deck when it is opened from the address above.
